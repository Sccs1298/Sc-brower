# UTM Nav: ניווט לקואורדינטת UTM ישירות מהשעון

אפליקציית SuuntoPlus ל-Suunto 5 Peak. מזינים נקודת UTM בכפתורי השעון, בשטח ובלי טלפון, והשעון מראה מרחק, אזימוט ולאן לפנות.

> **סטטוס:** הקוד נבדק אוטומטית: חישובי ה-UTM מדויקים ברמת מילימטר מול proj4, ולוגיקת הכפתורים נבדקה בסימולציה. **הוא עוד לא נבדק על שעון אמיתי.** הבדיקה הראשונה צריכה להיות בבית, לא בטיול.

## מה רואים על השעון

**מסך הזנה** (הספרה הפעילה בסוגריים):

```
 SET TARGET UTM
   Z [3]6 N
  E 684231
  N 3512345
 UP +1  DN next
```

**מסך ניווט:**

```
   BRG 047        ← אזימוט אמיתי ליעד
   1.24 km        ← מרחק
   LEFT 23        ← לאן לפנות (או ^ AHEAD ^ / ARRIVED)
   compass        ← מקור הכיוון: compass או by track
 Hold DN = new
```

## כפתורים

| מצב | כפתור | פעולה |
|---|---|---|
| הזנה | עליון | ספרה +1 |
| הזנה | עליון לחיצה ארוכה | ספרה −1 |
| הזנה | תחתון | ספרה הבאה. אחרי הספרה האחרונה: שמירה ומעבר לניווט |
| הזנה | תחתון לחיצה ארוכה | ספרה קודמת. על הספרה הראשונה: ביטול |
| ניווט | תחתון לחיצה ארוכה | הזנת נקודה חדשה |
| ניווט | עליון | הצגת הקואורדינטות של היעד, ולחיצה נוספת חוזרת |

**טריק שחוסך לחיצות:** כשנכנסים למסך ההזנה ויש GPS, הספרות כבר מכילות את **המיקום הנוכחי שלך**. נקודה בטווח של כמה קילומטרים נבדלת בדרך כלל רק ב-3–4 הספרות האחרונות, אז משנים רק אותן.

היעד נשמר בשעון ויחכה לך גם באימון הבא.

## מגבלות שחשוב לדעת

- **חצי כדור צפוני בלבד** (ישראל: אזור 36, ולפעמים 35 במערב). רשת ITM הישראלית לא נתמכת בגרסה הזו.
- **האפליקציה רצה רק בתוך אימון.** מתחילים אימון, למשל הליכה, ובוחרים בה (הוראות בהמשך).
- **בזמן שאתה במסך של UTM Nav**, הכפתור העליון והתחתון משמשים להזנה ולא לעצירה או להקפה. כדי לעצור אימון, עבור קודם למסך אחר עם הכפתור האמצעי.
- **מצפן:** משאב המצפן לא מתועד עבור ה-5 Peak. אם הוא לא זמין, האפליקציה מחשבת את **כיוון ההליכה** מה-GPS (`by track`). הכיוון הזה מתעדכן רק כשהולכים, בערך כל 12 מטר. אם יש מצפן, ודא שהגדרת סטייה מגנטית (declination) בהגדרות השעון. בישראל היא בערך 5° מזרח.
- **סנכרון עם אפליקציית Suunto עלול למחוק את האפליקציה** מהשעון, כי זו התקנת מפתח פרטית ולא אפליקציה מה-Store. אחרי סנכרון ייתכן שתצטרך להתקין אותה שוב מהמחשב.

## התקנה (פעם אחת, מהבית)

צריך **מחשב Windows או Mac**. ה-Editor של Suunto לא רץ בלינוקס, בטלפון או בטאבלט.

1. התקן את [Visual Studio Code](https://code.visualstudio.com/).
2. ב-VS Code, במסך התוספים (Extensions), התקן את **SuuntoPlus Editor** של Suunto.
3. הורד את התיקייה `suunto-utm-nav` מהריפו ופתח אותה ב-VS Code (File → Open Folder).
4. **מומלץ, בדיקה בסימולטור:** פתח את לוח הפקודות (`Ctrl+Shift+P` / `Cmd+Shift+P`) והרץ `SuuntoPlus: Start Simulator`. בחר תצוגה **s** (זו של ה-5 Peak), ובדוק שהמסך נראה טוב ושהכפתורים עובדים.
5. חבר את השעון למחשב בכבל ה-USB שלו.
6. הרץ `SuuntoPlus: Deploy to Watch`. אם יופיעו אזהרות או שגיאות, שלח לי אותן ואתקן.

## שימוש בשטח

1. בשעון: **Exercise**, ובחירת סוג אימון (למשל Hiking).
2. לפני ההתחלה, גלול ל-**SuuntoPlus** ובחר **UTM Nav**.
3. התחל את האימון, ולחץ על הכפתור **האמצעי** עד שמגיעים למסך של UTM Nav.
4. **לחיצה ארוכה על התחתון**, הזנת הספרות, ולחיצה על התחתון אחרי הספרה האחרונה. זהו, אתה מנווט.

## אם משהו לא עובד

- **מסך שחור או הודעת שגיאה:** הכלי של Suunto שומר יומן אירועים (`SuuntoPlus: Open Log Files`). שלח לי את השורות עם `ERR APPLICATION` ואתקן.
- **תמיד `NO HEADING` גם בהליכה:** ייתכן שה-GPS לא מעביר מיקום לאפליקציה. בדוק שבשורה העליונה מופיע `GPS 100%`.
- **הטקסט חתוך בקצוות המסך:** תצלם ואקצר.

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `manifest.json` | הגדרות האפליקציה והחיישנים שהיא קוראת |
| `main.js` | מעביר את מיקום ה-GPS ומחשב את כיוון ההליכה |
| `nav.html` | המסך, הכפתורים, חישובי UTM והניווט |
| `test/run-tests.js` | בדיקות אוטומטיות (`npm install && npm test`) |

כל הלוגיקה נמצאת ב-`nav.html` ולא ב-`main.js`, כי ה-5 Peak לא תומך ב-`onEvent`: לחיצות כפתור לא מגיעות ל-`main.js`.
