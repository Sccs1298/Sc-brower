# Drone3D – מידול תלת־ממדי חי מרחפן DJI

בזמן שמטיסים את הרחפן, המערכת בונה מודל תלת־ממדי של המבנה: מבחוץ – חזיתות, קומות, חלונות ודלת; ובפנים – הקירות, הרצפה והתקרה.

```
 רחפן DJI ──(שלט RC-N1/N2/N3)── טלפון אנדרואיד: אפליקציית Drone3D
                                  │  וידאו חי (JPEG, ~4 פריימים בשנייה) + טלמטריה
                                  │  (GPS, גובה, מהירות, זוויות גימבל)
                                  ▼  WebSocket באותה רשת Wi‑Fi / Hotspot
                        מחשב: שרת Drone3D (Python)
                        • מעקב חזותי (ORB + PnP) + התאמת צרורות (BA)
                          משולבת עם טלמטריית DJI → קנה מידה אמיתי במטרים
                        • עומק צפוף (Optical Flow) → ענן נקודות צבעוני
                        • ניתוח מבנה: קירות, רצפות, חלונות, דלתות, מספר קומות
                                  │
                                  ▼
                 צופה תלת־ממדי חי (בדפדפן ובתוך האפליקציה)
```

## אילו רחפנים נתמכים

האפליקציה בנויה על **DJI Mobile SDK v5** (גרסה 5.20.1). לפי רשימת המוצרים הנתמכים של DJI:

| רחפן | שלט נדרש |
|---|---|
| DJI Mini 4 Pro | DJI RC‑N2 / RC‑N3 (שלט שמתחבר לטלפון) |
| DJI Mini 3 Pro | DJI RC‑N1 / DJI RC Pro |
| DJI Mini 3 | DJI RC‑N1 |
| Mavic 3 Enterprise / 3M / 3TA | DJI RC Pro Enterprise |
| Matrice 4 / 4D / 30 / 300 / 350 / 400 | DJI RC Plus / RC Plus 2 |

**לא נתמכים ב־SDK:** Air 3 / Air 3S, Mavic 3 (הגרסה הצרכנית), **Avata ו־Avata 2**. גם שלט **DJI RC עם מסך מובנה** לא מתאים, כי אי אפשר להתקין עליו אפליקציות.
ל־**Avata 1/2** (ולכל רחפן שמוטס דרך DJI Fly):
- **אנדרואיד:** תוסף שרץ כולו על הטלפון – ראו "Drone3D Avata" למטה.
- **אייפון:** שיקוף מסך (AirPlay) למחשב נייד – ראו "אייפון" למטה.

## הפעלה

### 1. השרת (על המחשב)
```bash
cd drone3d/server
pip install -r requirements.txt
python -m drone3d.server --port 8080
```
אחר כך פותחים בדפדפן `http://<IP-של-המחשב>:8080/`. הטלפון והמחשב צריכים להיות באותה רשת.

### 2. האפליקציה (אנדרואיד)
1. נרשמים ב־[developer.dji.com](https://developer.dji.com/user/apps), יוצרים אפליקציה עם שם החבילה `com.drone3d.app` ומקבלים App Key.
2. מעתיקים את `android/local.properties.example` לקובץ `android/local.properties` ומכניסים לתוכו את המפתח ואת `sdk.dir`.
3. פותחים את התיקייה `android/` ב־Android Studio ומריצים על הטלפון (`./gradlew assembleDebug`).
4. בפעם הראשונה צריך אינטרנט, כדי ש־DJI תאשר את המפתח.
5. מחברים את הטלפון לשלט, מקלידים כתובת שרת (למשל `192.168.1.20:8080`), לוחצים "התחבר לשרת" ומפעילים את המתג "שידור למידול".

המסך מחולק לשניים: מצד שמאל הווידאו מהרחפן, ומצד ימין המודל שנבנה בזמן אמת. "סיים ושמור" שומר את הטיסה בתיקייה `server/sessions/<תאריך>/`.

### מצב וידאו בלבד (כל רחפן)
```bash
python -m drone3d.server --source rtmp://<שרת-RTMP>/live/drone --hfov 73.7
```
ב־DJI Fly בוחרים שידור חי ← RTMP, אל שרת RTMP מקומי (למשל mediamtx).

## Drone3D Avata – תוסף שרץ על הטלפון (Avata 1 ו־2)

ל־Avata אין גישת SDK, ולכן התוסף עובד אחרת: הוא **מצלם את המסך של DJI Fly** (התמונה החיה שמגיעה מהמשקפות לטלפון), **ממדל על הטלפון עצמו** – בלי מחשב – ומציג את המודל ב**חלון צף מעל DJI Fly**.

```
 Avata ── משקפות (Goggles 2 / Integra / 3 / N3) ──USB-C── טלפון
                                                     │
                     DJI Fly מציגה את התמונה החיה ────┤
                                                     ▼
            Drone3D Avata (אותו טלפון): צילום מסך ~3 פעמים בשנייה
            • מיסוך תצוגת DJI Fly (גובה, מהירות, סוללה, אייקונים) – מזוהה אוטומטית
            • תיקון עיוות העדשה הרחבה (כיול פעם אחת עם לוח שחמט)
            • קריאת הגובה H מהמסך (זיהוי טקסט) ← קנה מידה אמיתי במטרים
            • "למטה" לפי האופק הישר של Avata + הרצפה/הקרקע
            • אותו מנוע מידול (Python, רץ על הטלפון)
                                                     ▼
                         חלון צף מעל DJI Fly: מודל תלת־ממדי חי
```

### התקנה
1. צריך Android Studio ו־**Python 3.10** במחשב (רק לבנייה). ב־`android/local.properties` מוסיפים:
   `chaquopy.buildPython=<נתיב ל־python3.10>`.
2. ב־Android Studio בוחרים את המודול **avata** ← Run, כשהטלפון מחובר בכבל (`./gradlew :avata:assembleDebug`).
   ל־Avata **לא צריך** מפתח DJI.

### שימוש
1. **הרשאה:** "הענק הרשאה" ← מאשרים הצגה מעל אפליקציות אחרות.
2. **כיול עדשה (פעם אחת):** "שתף את לוח הכיול" ← מדפיסים אותו או מציגים במסך מחשב. מחברים את הטלפון למשקפות, ובלי להמריא (עם מגני מדחפים!) מזיזים את הרחפן ביד מול הלוח מכמה זוויות ומרחקים. כשמגיעים ל־12/12 תצוגות לוחצים "סיים כיול" בחלון הצף.
3. **טיסה:** "התחל" ← מאשרים צילום מסך ← DJI Fly נפתחת עם חלון המודל הצף.
   - מיד אחרי ההמראה **מטפסים ישר למעלה 2–3 מ'**. התוסף קורא את H מהמסך וקובע מזה את המידות. ובהמשך, כל עלייה או ירידה מתקנת את קנה המידה מחדש.
   - בחלון הצף רשום "H=…". אם רשום "H לא נקרא": לוחצים 📏, מקלידים את H, מטפסים ישר מטר וחצי ומסמנים שוב.
   - טסים במצב **Normal** (האופק נשאר ישר), לאט (עד ~2 מ' לשנייה), ומסתובבים מדי פעם.
   - הכפתורים בחלון: ⏸ עוצר את המידול, ⤢ מגדיל את החלון לתצוגה מלאה, ✕ מסיים.
4. **אחרי הטיסה:** "שתף מודל (PLY)" שולח את המודל (למחשב, ל־Drive וכו'). ההקלטה המלאה נשמרת ב־`Android/data/com.drone3d.avata/files/sessions`.

### דיוק (טיסה סינתטית בסגנון Avata: תצוגת DJI Fly על התמונה, עיוות עדשה, בלי שום טלמטריה)
| מדד | תוצאה |
|---|---|
| כיול עדשה | מוקד ומקדמי עיוות נמצאו בטווח של 0.5% מהאמת |
| כיוון "למטה" | סטייה של 0.2–1.2° |
| קנה מידה (מ־H במסך) | שגיאה של 1–6% |
| מסלול | חציון 4–7 ס"מ |
| נקודות בחוץ / בפנים | חציון 6–9 ס"מ / 17–27 ס"מ |

### מה עוד לא ידוע (צריך טיסה אמיתית)
- **צילום מסך:** אם DJI Fly חוסמת צילום מסך, החלון יציג "המסך שחור". במקרה כזה צריך פתרון אחר: הקלטה במשקפות ועיבוד אחרי הטיסה.
- **הפורמט של H על המסך:** זיהוי הטקסט מחפש "H 12.3m", "H 40ft" או "ALT". אם DJI Fly מציגה אותו אחרת, צריך לעדכן את התבנית ב־`HeightReader.kt`, ובינתיים משתמשים בסימון ידני.
- **מצב Manual (אקרו):** האופק לא ישר, ולכן כיוון "למטה" מוערך פחות טוב.
- **ביצועים:** במחשב, עיבוד של פריים לוקח כ־100 ms. על טלפון זה צפוי להיות פי 2–4 יותר. לכן ברירת המחדל היא 3 פריימים בשנייה (ניתן לשנות).

## אייפון (Avata 1/2 עם iPhone) – מידול חי דרך מחשב נייד

באייפון אי אפשר להתקין את התוסף: אפליקציה ל־iOS נבנית רק על Mac, ו־iOS לא מאפשר לצייר מעל DJI Fly. לכן משתמשים ב**שיקוף מסך (AirPlay)** שמובנה באייפון: מה ש־DJI Fly מציגה מועבר בזמן אמת למחשב נייד, והמחשב ממדל ומציג את המודל. **באייפון לא מתקינים כלום.**

```
 Avata ── משקפות ──USB-C── iPhone (DJI Fly)
                               │  שיקוף מסך (AirPlay) – באותה רשת Wi‑Fi
                               ▼
        מחשב נייד: מקלט AirPlay (חלון עם המסך של האייפון)
                   + python -m drone3d.server --airplay
                     • מצלם את החלון ~3 פעמים בשנייה, חותך את הפסים השחורים
                     • קורא את הגובה H מהמסך (Tesseract) ← מידות אמיתיות
                     • אותו מנוע מידול כמו של Avata
                               ▼
                 מודל תלת־ממדי חי בדפדפן: http://localhost:8080
```

### התקנה במחשב (פעם אחת)
1. **מקלט AirPlay:** תוכנה שמציגה את מסך האייפון בחלון.
   - UxPlay – חינמי וקוד פתוח, ללינוקס ולווינדוס. בווינדוס צריך גם את Bonjour של Apple.
   - יש גם תוכנות מוכנות לווינדוס, כמו AirServer, ‏LonelyScreen או 5KPlayer.
   - לא בדקתי אף אחת מהן בעצמי. כל מקלט שמציג את המסך בחלון יעבוד.
2. **Python 3.10 ומעלה**, ואז:
   ```bash
   cd drone3d/server
   pip install -r requirements-iphone.txt
   ```
3. **Tesseract**, בשביל קריאת הגובה H:
   - בווינדוס: המתקין של UB Mannheim, ולהוסיף אותו ל־PATH.
   - בלינוקס: `sudo apt install tesseract-ocr`.
   - בלי Tesseract הכול עובד, אבל את H מקלידים ידנית בכפתור "קנה מידה".

### בשטח
1. **רשת:** המחשב והאייפון צריכים להיות באותה רשת. בשטח אפשר להפעיל נקודה חמה ב**מחשב** ולחבר אליה את האייפון.
2. **הפעלת המקלט:** פותחים את מקלט ה־AirPlay ומגדילים את החלון למסך מלא.
3. **שיקוף מהאייפון:** מרכז הבקרה ← "שיקוף מסך" ← בוחרים את המחשב. אחר כך פותחים את DJI Fly ומחברים את המשקפות.
4. **הפעלת השרת:**
   ```bash
   python -m drone3d.server --airplay
   ```
   - אם המקלט לא במסך מלא, מוסיפים `--window UxPlay` (חלק משם החלון).
   - במחשב עם כמה מסכים מוסיפים `--monitor 2`.
5. **צפייה במודל:** פותחים `http://localhost:8080` בדפדפן. אפשר על מסך שני, או לעבור בין החלונות.
6. **כיול עדשה (פעם אחת):** בצופה לוחצים "קנה מידה" ← "התחל כיול".
   - מזיזים את הרחפן ביד מול לוח השחמט, מודפס או מוצג במסך אחר, עד 12 תצוגות, ואז "סיים כיול".
   - הכיול נשמר בקובץ `calibration.json`.
7. **טיסה:** מטפסים ישר למעלה 2–3 מ' מיד אחרי ההמראה, טסים במצב Normal ולאט.

הבדיקה עברה את כל השלבים: חלון "שיקוף" עם פסים שחורים, צילום מסך, קריאת H מהפיקסלים, מיסוך תצוגת DJI Fly ותיקון עדשה.

| מדד | תוצאה |
|---|---|
| גובה הבניין | 6.23–6.33 מ' (במציאות 6.5) |
| קומות | 2 ✓ |
| דלת | ‎2.02×2.13 מ' (במציאות ‎2×2.2) |
| חלונות | ‎2.1×1.1 מ' (במציאות ‎2×1.2) |

קריאת H: 30 מתוך 34 פריימים נקראו נכון, 2 עם טעות של 0.3 מ', ו־2 לא נקראו.

**לא נבדק עדיין:**
- **השהיה:** שיקוף AirPlay מוסיף בערך 0.1–0.3 שניות. זה לא אמור להפריע למידול.
- **חסימה:** אם DJI Fly חוסמת שיקוף מסך, צריך לנסות פתרון אחר.
- **צורת H על המסך:** אם DJI Fly מציגה את הגובה בצורה אחרת מ־"H 12.3m", צריך לעדכן את התבנית ב־`capture.py`.

## טיפים לטיסה
- **התחלה:** מטיסים הצידה לאט כמה מטרים, מול המבנה. כך המערכת מאתחלת.
- **בחוץ:** טסים בקשת סביב הבית, במרחק 10–20 מ' ובכמה גבהים, עם הגימבל מעט כלפי מטה.
- **מעבר דרך דלת:** טסים לאט וישר. סיבוב במקום מבלי לזוז לא מוסיף עומק.
- **בפנים:** זזים לאורך החדר תוך כדי סריקה. קירות לבנים וחלקים קשים לכל שיטה חזותית.

## מגבלות (חשוב לדעת)
- **המערכת לא נבדקה עדיין עם רחפן אמיתי.** השרת נבדק על נתונים סינתטיים, והאפליקציה נבנית מול ה־SDK האמיתי של DJI, אבל לא הורצה על רחפן. בטיסה הראשונה צפויים כיוונונים (שדה ראייה, מוסכמת זווית הגימבל וכו').
- **בפנים הדיוק נמוך יותר:** כ־20–30 ס"מ. ביציאה ממסלול ה־GPS דרך הדלת מצטברת סטייה קטנה בין המודל הפנימי לחיצוני. אין עדיין "סגירת לולאה".
- **חלונות מזוהים כחורים בחזית.** זכוכית לא מחזירה נקודות, ולכן החלון נראה כחור. חזית שלא צולמה עלולה להיראות כחור ולהיספר בטעות כחלון.
- **שדה הראייה:** ברירת המחדל היא 73.7° (מצלמה של 24 מ"מ). לרחפן אחר מגדירים `--hfov`.

## מודל מדויק יותר אחרי הטיסה
"סיים ושמור" כותב לתיקיית ההקלטה את הקבצים `model.ply`, `structure.json` ו־`transforms.json` (תנוחות המצלמה בפורמט nerfstudio). את הקבצים האלה אפשר להזין ל־Gaussian Splatting, NeRF או פוטוגרמטריה (COLMAP / Metashape) ולקבל מודל מדויק בהרבה, כולל רשת (mesh).

## מבנה הקוד
```

server/drone3d/ba.py         Bundle Adjustment (Levenberg‑Marquardt + Schur) עם טלמטריה
server/drone3d/telemetry.py  המרת טלמטריית DJI לתנוחה (GPS בחוץ, מהירויות בפנים)
server/drone3d/structure.py  מישורים, קומות, חלונות ודלתות
server/drone3d/server.py     שרת WebSocket/HTTP, הקלטה וייצוא
```
