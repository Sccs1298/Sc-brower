# מערכת ל-₪100,000 בחודש: מוצרים דיגיטליים ופרסום ממומן

## 2. המשפך
```
מודעה (רילס ממומן בסגנון שלנו)
  → דף נחיתה של הערכה (₪79)
    → עמוד תשלום + תוספת (₪39)
      → עמוד אפסייל (₪297, לחיצה אחת)
        → עמוד תודה ומסירת המוצר
          → רצף 14 מיילים / וואטסאפ → קורס הדגל (₪997)
פיקסל ו-CAPI → רימרקטינג למי שהגיע ולא קנה (צופי סרטונים, מבקרים בדף)
```

## 3. המספרים בחודש היעד
*הנחות לבדיקה. המספרים האמיתיים ייקבעו בשלב הבדיקות.*

| שורה | הנחה | תוצאה |
|---|---|---|
| תקציב פרסום | — | ₪50,000 |
| עלות קליק (מטא, קהל ישראלי) | ₪2.5 | 20,000 קליקים |
| המרה בדף הנחיתה | 3.5% | **700 קונים** |
| ערכה | 700 × ₪79 | ₪55,300 |
| תוספת בקופה | 35% × ₪39 | ₪9,555 |

| קורס דגל ממיילים | 2% מכ-2,000 קונים שהצטברו × ₪997 | ₪39,880 |

| הכנסה בלי מע"מ (18%) | | כ-₪106,000 |
| פחות פרסום, סליקה (כ-3%) וכלים | | **רווח של כ-₪50,000** |

> **שימו לב:** ₪100K בהכנסות זה לא ₪100K ברווח. כדי לשים ₪100K נטו בכיס צריך בערך ₪220–250K הכנסות בחודש, כלומר תקציב פרסום של כ-₪100K.

### המדד שמחליט הכל: ROAS (הכנסות חלקי תקציב פרסום)
| ROAS | משמעות |
|---|---|
| מתחת ל-1 | מפסידים. מתקנים מודעה, דף או הצעה לפני שמגדילים תקציב |
| 1–1.5 | המשפך מחזיר את עצמו. הרווח מגיע מהמיילים ומקורס הדגל |
| **2–2.5** | **רווחי. מגדילים תקציב ב-20–30% כל כמה ימים** |

## 4. התוכן: מכונה למודעות, לא מקור ההכנסה

| **רימרקטינג** | מי שצפה ב-50% מרילס נכנס לקהל, ורואה מודעה ישירה לערכה |

## 6. תשתית
- **דף נחיתה ותשלום:** עמוד מהיר, עם תוספת בקופה ואפסייל בלחיצה אחת. סליקה ישראלית עם חשבונית אוטומטית.
- **מסירת מוצר:** אזור לקוחות לקורסים והורדת ה-PDF מיד אחרי התשלום.
- **מעקב:** פיקסל ו-Conversions API של מטא, אירועי רכישה עם ערך, ו-UTM לכל מודעה.
- **מיילים ווואטסאפ:** רצף אוטומטי אחרי הרכישה.
