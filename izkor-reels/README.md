# יזכור – רילס יומי לזכר חללי מערכות ישראל

מערכת אוטומטית שמפרסמת באינסטגרם סרטון רילס לזכרו של כל אחד מחללי מערכות ישראל, מהנופל האחרון ועד הראשון.

## עקרונות
- **רק מידע מאומת.** כל הנתונים (שם, דרגה, יחידה, תאריכים, הורים, מקום מנוחה, תמונה וסיפור חיים) נלקחים מ[אתר יזכור](https://www.izkor.gov.il) של משרד הביטחון.
- **שום טקסט לא מומצא ושום דבר לא מנוסח מחדש.** ציטוט בסרטון חייב להופיע מילה במילה בסיפור החיים הרשמי. המערכת בודקת את זה ונכשלת אם הוא לא מופיע.
- **התמונה הרשמית בלבד.** לא משתמשים ב-AI כדי ליצור או לשנות פנים.
- **המוזיקה מקורית.** היא מסונתזת בקוד (`izkor_reels/music.py`), ואין צורך בזכויות.
- **לא מפרסמים בשבת.**
- **רשומה חסרה לא מתפרסמת.** היא נרשמת ב-`state/skipped.json` לבדיקה ידנית.

## מבנה הסרטון (כ-37 שניות, 1080×1920)
1. תמונה ממוסגרת עם דרגה, שם ויחידה.
2. תאריך הנפילה (עברי ולועזי), הגיל בנפילה, שמות ההורים ומקום המנוחה, עם נר.
3. ציטוט מילולי מסיפור החיים (בדרך כלל מהספד של בן משפחה), עם שם הדובר.
4. נר זיכרון, "יהי זכרו ברוך" וקרדיט למקור.

## הקמה
1. **חשבון אינסטגרם מקצועי** (Business או Creator).
2. **אפליקציה ב-[Meta for Developers](https://developers.facebook.com)** עם הרשאת `instagram_content_publish`, ו-Access Token לטווח ארוך.
3. **Secrets ב-GitHub** (Settings → Secrets and variables → Actions):
   - `IG_USER_ID`
   - `IG_ACCESS_TOKEN`
   - אם התחברתם דרך Instagram Login ולא דרך Facebook Login, הגדירו את המשתנה `IG_GRAPH_HOST=graph.instagram.com` (תחת Variables).
4. **ריצת בדיקה:** הפעילו ידנית את ה-workflow ב-Actions עם `dry_run`, והורידו את הסרטון מה-Artifacts.

## הרצה מקומית
```bash
sudo apt-get install ffmpeg libraqm0
pip install -r requirements.txt
python -m izkor_reels.main --dry-run                     # הנופל הבא בתור
python -m izkor_reels.main --dry-run --legacy-id 520128  # נופל מסוים
```
הקבצים נשמרים ב-`output/<legacy_id>/`: `reel.mp4` ו-`caption.txt`.

## בחירה ידנית של ציטוט (אופציונלי)
יוצרים את הקובץ `overrides/<legacy_id>.json`:
```json
{"excerpt": "טקסט מילה במילה מסיפור החיים", "speaker": "אימו, אולגה"}
```
כדי לוותר על ציטוט: `{"excerpt": null}`. גם ציטוט שנבחר ידנית נבדק מול הטקסט הרשמי.

## סדר הפרסום
המערכת עוברת על הרשימה לפי הסדר של אתר יזכור, מהאחרון לראשון. נופל שמתווסף לאתר יפורסם בריצה הבאה, לפני שהמערכת ממשיכה ברצף. ההתקדמות נשמרת ב-`state/published.json`.
