# 🎲 שש בש כפול – בטא

פלטפורמת שש בש שמבוססת על מיומנות, עם מצב **שש בש כפול**: שני לוחות, אותן קוביות, והמזל מתבטל.
**גרסת הבטא היא ללא כסף אמיתי:** משחקים על נקודות בטא שאין להן ערך כספי.

## הרצה

```bash
cd shesh-besh
npm install
npm start          # http://localhost:3000
npm test           # 21 בדיקות: חוקים, קוביות, שרת מקצה לקצה
npm run study      # מחקר מיומנות מול מזל (כ-3.5 דקות), מעדכן את docs/skill-study.md
```

משתני סביבה: `PORT`, `DB_FILE` (ברירת מחדל: `data/db.json`), `ADMIN_TOKEN` (מפעיל את `/admin/stats` ו-`/admin/audit`), `BOT_DELAY_MS`, `RATE_LIMIT`.

## מה יש בבטא

| תחום | מה בנוי |
|---|---|
| **מנוע חוקים** | חוקי שש בש מלאים: בר, הכאה, הוצאה, חובה לנצל מקסימום קוביות, קוביית הכפלה, קרופורד, גמון ובקגמון |
| **מצבי משחק** | קלאסי (משחק בודד או עד 3, 5 או 7) ושש בש כפול (1 עד 3 סבבים, שני לוחות במקביל) |
| **קוביות שקופות** | התחייבות מראש (commit-reveal) עם HMAC-SHA256 וזרע משותף לשחקנים. דף אימות שרץ בדפדפן (`/verify.html`) |
| **יריבים** | תור התאמה לשחקנים אנושיים, ומשחק נגד בוט בארבע רמות |
| **טורנירים** | 4 שחקנים בשיטת הדחה. כללים ופרסים שמתפרסמים מראש. טורניר אימון חינמי (בוטים משלימים מקומות) וטורניר נקודות (בני אדם בלבד) |
| **חשבונאות** | ספר חשבונות כפול (double-entry) לנקודות בטא, עם בדיקת איזון. מוכן מבנית לשלב 2 |
| **דירוג** | Elo. משחק בשש בש כפול מקבל משקל גבוה יותר |
| **משחק הוגן** | מדד איכות מהלכים מול המנוע, זיהוי התאמה חשודה למנוע או מהירות חשודה, ואותה רשת אצל שני יריבים. כל סימון נבדק ידנית |
| **משחק אחראי** | מגבלת דמי כניסה יומית (העלאה רק אחרי 24 שעות), תזכורות זמן והחרגה עצמית |
| **גיל** | 18 ומעלה, ונשמרת רק שנת הלידה |
| **ראיות** | `/api/evidence`: באיזו תדירות השחקן בעל הדירוג הגבוה יותר מנצח, לפי פורמט |
| **מסמכים** | [תקנון](docs/terms.md) (כולל נספח "למה זה לא הימורים"), [מחקר מיומנות](docs/skill-study.md), [פרטיות](docs/privacy.md), [משחק אחראי](docs/responsible-play.md), [נגישות](docs/accessibility.md) |
| **פנימי (לעו"ד)** | [ניתוח משפטי ותיק גיבויים](legal/legal-analysis.md). המסמך לא מוגש לציבור |

## מבנה

```
src/engine/   מנוע חוקים, זרימת משחק ובוט. JS טהור שרץ גם בדפדפן
src/server/   קוביות, שרת, חשבונאות, דירוג, משחק הוגן ושמירת נתונים
public/       ממשק המשתמש (עברית, RTL)
scripts/      מחקר מיומנות מול מזל
docs/         מסמכים ציבוריים
legal/        מסמכים פנימיים
test/         בדיקות
```
