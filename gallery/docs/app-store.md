# מה צריך כדי להעלות את "גלריה" ל-App Store

## 1. חשבון ומחיר
- **Apple Developer Program**: בערך 99$ לשנה. אפשר להירשם כאדם פרטי (אימות זהות) או כחברה (צריך מספר D-U-N-S).
- אם מוכרים את האפליקציה, אפל לוקחת 15% (תוכנית לעסקים קטנים, עד מיליון דולר בשנה) או 30%.

## 2. הפיכה לאפליקציה אמיתית (לא רק אתר)
- עוטפים את הקוד הקיים ב-**Capacitor**. הקוד נשאר אותו קוד, ומוסיפים יכולות של אפליקציה רגילה.
- **חובה להוסיף ערך מעבר לאתר** (סעיף 4.2 בהנחיות: "פונקציונליות מינימלית"). אצלנו זה טבעי:
  - **רטט אמיתי** (Haptics) בכל הקשה סודית. באייפון אין רטט מדפדפן, ובאפליקציה יש.
  - **כפתורי עוצמת הקול** כשיטת הזנה סודית (רק אפליקציה רגילה יכולה לקרוא אותם).
  - **ייבוא ישיר מגלריית התמונות** ושמירה של הסרטון המשותף לגלריה.
  - עבודה מלאה בלי אינטרנט.
- **בנייה בלי מק**: GitHub Actions עם מחשב macOS בענן, או שירותים כמו Capgo או Capawesome, שבונים, חותמים ומעלים ל-TestFlight. עם מק: Xcode.

## 3. מה ייפסל, ואיך נמנעים
| סיכון | הנחיה | מה עושים |
|---|---|---|
| אייקון ושם שמחקים את אפליקציית התמונות של אפל | 5.2.5 (אסור להיראות כמו מוצר של אפל) | **אייקון ושם משלנו** בחנות. ההסוואה כגלריה נשארת רק בתוך האפליקציה, בעיצוב כללי ולא העתק מדויק. |
| תכונות נסתרות | 2.3.1 (אסור תכונות לא מתועדות) | בהערות לבודק מסבירים במפורש: "אפליקציית קסמים. לחיצה ארוכה על הכותרת פותחת ניהול", עם סרטון הדגמה. |
| "סתם אתר עטוף" | 4.2 | התכונות של סעיף 2 למעלה. |
| תיאור לא מדויק | 2.3 | צילומי מסך אמיתיים, בלי הבטחות שהאפליקציה לא עושה. |

## 4. מה צריך להכין ב-App Store Connect
- **שם ותת-כותרת**, למשל: "גלריה: חיזוי בסרטון".
- **אייקון 1024×1024** בעיצוב מקורי.
- **צילומי מסך** לאייפון 6.9 אינץ' (1320×2868). לאייפד רק אם תומכים באייפד.
- **תיאור, מילות מפתח, קטגוריה** (בידור).
- **מדיניות פרטיות (קישור)**. אצלנו פשוט: שום מידע לא נאסף ("Data Not Collected").
- **דירוג גיל, כתובת תמיכה, הערות לבודק + סרטון הדגמה.**

## 5. מודל מכירה מומלץ
- קנייה חד-פעמית או ניסיון חינם + רכישה אחת. המתחרים יקרים (50–300$) או במנוי, ומשתמשים מתלוננים על זה.

## 6. סדר פעולות
1. נרשמים ל-Apple Developer (יום–יומיים לאישור).
2. מוסיפים Capacitor + רטט + כפתורי עוצמה + ייבוא מהגלריה.
3. מעצבים אייקון ושם משלנו לחנות.
4. בונים ומעלים ל-**TestFlight**, ובודקים על אייפון אמיתי.
5. מכינים צילומי מסך, תיאור, מדיניות פרטיות והערות לבודק.
6. שולחים לבדיקה (בדרך כלל 1–3 ימים).
